# النسخة المعدلة من نظام المحاسبة

هذه النسخة تحافظ على واجهات WPF الحالية، وتضم تعديلات مواءمة مع نموذج الأونكس الوارد في ملف PDF المرجعي. ابدأ بقراءة `Docs/تقرير_تحليل_ومواءمة_نظام_المحاسبة.md` قبل تشغيل المشروع.

## أهم الملفات

| المسار | الوظيفة |
|---|---|
| `Database/01_OnyxAlignedSchema.sql` | مخطط SQL والعلاقات والجداول والإجراء المخزن الخاص بالقيود. |
| `DbConnectionFactory.cs` | مصدر الاتصال المركزي من `App.config`. |
| `Repositories/AccountRepository.cs` | دليل الحسابات الهرمي والتحقق من الحسابات القابلة للترحيل. |
| `Repositories/VoucherDAL.cs` | حفظ القيود المتوازنة عبر TVP وإجراء SQL. |
| `Services/PurchaseService.cs` | حفظ فاتورة الشراء والدفعة وحركة الإدخال ورصيد المورد ذريًا. |
| `Services/InventoryService.cs` | قراءة الدفعات والتنبيهات حسب الفرع وتاريخ الصلاحية. |
| `FastPOSWindow.xaml.cs` | دورة نقطة البيع والوردية وتخصيص FIFO وحركة الإخراج. |
| `Docs/تقرير_تحليل_ومواءمة_نظام_المحاسبة.md` | التحليل الكامل والقيود المعروفة ونتائج الفحص. |

## التشغيل

يفتح المشروع باستخدام Visual Studio 2022 على Windows مع workload تطبيقات سطح المكتب .NET. المشروع يستهدف `.NET Framework 4.7.2`، لذلك يلزم توفر Developer Pack المناسب. عدّل سلسلة `DefaultConnection` داخل `App.config` قبل التشغيل، ثم نفّذ `Database/01_OnyxAlignedSchema.sql` على قاعدة SQL Server المطلوبة.

بعد التهيئة، أنشئ الشركة والفرع والسنة والفترات المفتوحة، ثم دليل الحسابات والأصناف والدفعات. لا تجرب البيع قبل وجود دفعات فعلية للصنف وفترة مالية تغطي تاريخ اليوم.

## ملاحظة الترحيل

حفظ المستندات والحركات المخزنية موحد داخل معاملات قاعدة البيانات. أما إنشاء القيد التلقائي لكل شراء أو بيع فيحتاج إلى تحديد أكواد حسابات المخزون والمبيعات وتكلفة المبيعات والصندوق أو البنك والمورد والعميل داخل إعدادات الشركة؛ لذلك لم يتم وضع أكواد محاسبية افتراضية قد تنتج قيودًا خاطئة.

## الاختبار

تم إجراء فحص XML، وأحداث XAML، وعقود الجداول المستخدمة في الملفات الأساسية، والاتصالات الصلبة. النتيجة الحالية: `errors: 0` و`warnings: 0`. لم يتم تنفيذ Build فعلي داخل بيئة Linux لعدم توفر MSBuild الخاص بـWPF وSQL Server محليًا، ولذلك يجب إجراء التجميع والتجربة النهائية على Windows.
