# yotta soft — OnyxPro-aligned ERP

نظام محاسبي وERP مكتبي مبني بـ **WPF** و **.NET Framework 4.7.2** و **SQL Server**، مع الحفاظ على الواجهات الحالية وإعادة تنظيم طبقة البيانات والخدمات لتقترب من دورة نظام الأونكس برو 7/8.

## نطاق المشروع

- الأستاذ العام: شركة، فروع، سنوات وفترات مالية، دليل حسابات هرمي، مراكز تكلفة، قيود يومية.
- المخزون والمبيعات: الأصناف، الدفعات، الصلاحيات، حركة المخزون، المشتريات، المبيعات، المرتجعات، ونقطة البيع FIFO.
- الأصول الثابتة: بطاقات الأصول، فئات الأصول، الإهلاك الدوري وربط القيود.
- أوراق القبض والدفع: الشيكات والكمبيالات وحالات التحصيل والسداد والحسابات الوسيطة.
- الموارد البشرية والرواتب: الموظفون، الأقسام، مسيرات الرواتب، البدلات، الخصومات، السلف والعهد.
- البنوك: حسابات البنوك المرتبطة بدليل الحسابات وتسويات كشف البنك.
- الاستيراد والاعتمادات: الاعتمادات المستندية، مصاريف الشحن والجمارك والتخليص، وتوزيع التكلفة على الأصناف.

## البنية

| المسار | المحتوى |
|---|---|
| `Database/01_OnyxAlignedSchema.sql` | المخطط الأساسي للأستاذ العام والمخزون والمبيعات. |
| `Database/02_AdvancedErpModules.sql` | جداول الوحدات المتقدمة: الأصول، الشيكات، HR، البنوك، والاستيراد. |
| `DbConnectionFactory.cs` | مصنع اتصال مركزي يقرأ `DefaultConnection` من `App.config`. |
| `Repositories/` و`Services/` | الوصول إلى البيانات والخدمات التشغيلية. |
| `Docs/` | تقرير التحليل والمواءمة وملاحظات التشغيل. |

## التشغيل على Windows / Visual Studio

1. ثبّت Visual Studio 2022 مع workload **.NET desktop development** وDeveloper Pack لـ .NET Framework 4.7.2.
2. افتح `accounting_project.csproj`، ثم احفظ الحل من **File > Save All** أو بالاختصار `Ctrl+Shift+S`.
3. عدّل `DefaultConnection` في `App.config` لقاعدة SQL Server لديك.
4. نفّذ `Database/01_OnyxAlignedSchema.sql` أولًا، ثم `Database/02_AdvancedErpModules.sql`.
5. نفّذ Restore للـNuGet ثم Build للمشروع. عند ظهور رسالة `NuGetUnsavedSolution` احفظ الحل قبل استخدام `Update-Package -Reinstall`.
6. أنشئ الشركة والفرع والسنة والفترات، ثم الحسابات القابلة للترحيل والأصناف والدفعات قبل اختبار المبيعات.

## ملاحظات التصميم

- الواجهات WPF الحالية محفوظة؛ التغيير الأساسي في المخطط والـDAL والخدمات.
- الأمان بسيط كما طُلب: لا توجد Identity أو تشفير ثقيل. يجب حماية سلسلة الاتصال وملف قاعدة البيانات في بيئة الإنتاج.
- القيود المحاسبية لا تستخدم حسابات افتراضية غير معروفة؛ يجب تعريف حسابات المخزون والمبيعات والتكلفة والصندوق/البنك والموردين والعملاء.
- لم يتم تنفيذ Build فعلي لـWPF داخل Linux؛ يلزم اختبار التجميع وقاعدة SQL Server على Windows.

تمت مواءمة التصميم مع ملفات شرح نظام الأونكس المرفقة بالمشروع، مع فصل المخطط الأساسي عن الوحدات المتقدمة لتسهيل الترحيل والتشغيل المرحلي.
